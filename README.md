# نيزك - من قال هذه الجملة؟ 📜 | NAYZAK Quiz

لعبة مسابقات واقتباسات ثقافية تفاعلية تعتمد على تخمين قائل العبارة بين 6 من عظماء التاريخ مع تعليقات مضحكة باللهجة الشامية وتصميم مخصص للإنستغرام بايو وتطبيق أندرويد متكامل.

## 🚀 محتويات المستودع:
- **`index.html`**: لعبة الويب الكاملة الجاهزة للنشر المباشر على Cloudflare Pages أو GitHub Pages (تطبيق ويب تفاعلي PWA خفيف وسريع).
- **`app/`**: كود تطبيق أندرويد الأصلي المبني بأحدث تقنيات Jetpack Compose و Material Design 3.

## 🌟 ميزات لعبة الويب:
- تصميم فخم بكروت زرقاء سماوية فاتحة وشعار نيزك الذهبي على قرص أسود ملكي.
- مؤثرات صوتية مدمجة عبر Web Audio API.
- زر مشاركة فيروسي إلى Instagram Stories و WhatsApp.
- جاهزة للتتبع عبر Google Analytics 4.
